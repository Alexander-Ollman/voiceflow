## Findings addressed in the combined branch

### High: retain the previous installation until promotion succeeds (#8)

The relocation path removed the existing `/Applications/VoiceFlow.app` before
renaming the staged copy. A failed final rename could leave the user without an
installed application. `AppBundleInstaller.promote` now keeps a uniquely named
backup and rolls it back if promotion fails. Temporary staging is cleaned up on
both success and failure. A failed quarantine-cleanup process launch no longer
calls `waitUntilExit()` on a process that never started.

### Medium: restore the latest external Globe preference (#7)

While a Globe binding is active, every fn press reclaims the system action. If
the user or another app changes it from Emoji to Dictation, the original code
keeps the first saved value and later restores Emoji. Claim now remembers the
latest nonzero external choice. Restore also retains its recovery record if the
system write fails or the system state is unknown, so another attempt or launch
can recover it. A choice changed externally without another claim is untouched.

### Medium: avoid restoring an old foreground app from the background (#6)

Closing Settings previously activated the app remembered when Settings opened,
even if VoiceFlow was no longer active. The remembered app is now activated only
when VoiceFlow is active at close time.

## Visual update

The recording waveform is centered and wider, with a restrained dark surface.
Thirty-seven real microphone-level samples replace the old five bars; a single
Canvas draws the history. No waveform timer or synthetic sine animation runs.
History remains bounded, clears naturally during silence, and resets at the
start of a recording. The waveform has no interpolation or pulsing, including
when Reduce Motion is enabled. It represents amplitude history, not frequency
analysis or a speech-recognition confidence score.

The original working checkout also has an unfinished domain/UI migration. Its
recording-only operation overlay was updated in place to use the same waveform,
with the frozen target label underneath. Those existing migration files are not
copied into this branch. Its native rendered preview is available in that
checkout at `docs/reviews/waveform-preview.png`.
